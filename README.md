# AWS Static Website Deployment

## Overview

This project demonstrates the automated deployment of a static website using Amazon S3 and AWS CodePipeline.

The website is developed using HTML and CSS, with GitHub serving as the source code repository. AWS CodePipeline is used to automate the deployment of website files to an Amazon S3 bucket whenever changes are pushed to the main branch.

## Objectives

- Create and host a static website using Amazon S3.
- Store website source code in a GitHub repository.
- Configure AWS CodePipeline for automated deployment.
- Understand continuous integration and continuous delivery (CI/CD).
- Observe automatic website updates after changes to the source code.

## Technologies Used

- HTML
- CSS
- GitHub
- Amazon S3
- AWS CodePipeline

## Deployment Workflow

1. Create and configure an Amazon S3 bucket for static website hosting.
2. Develop the website using HTML and CSS.
3. Store the website files in a GitHub repository.
4. Configure AWS CodePipeline to connect GitHub with Amazon S3.
5. Automatically deploy website updates whenever changes are pushed to the main branch.

## Website

The website contains a simple homepage with a welcome message and information about the AWS CI/CD assignment.

## Learning Outcomes

- Understanding static website hosting using Amazon S3.
- Learning how GitHub integrates with AWS CodePipeline.
- Understanding automated deployment workflows.
- Observing how source code changes are reflected in a deployed website.
